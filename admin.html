Connect your GitHub account

You need a personal access token so this page can save changes to your site's repository. It's created once and stored only in this browser.

How do I get a token?
  1. Open github.com/settings/tokens/new while signed in to your GitHub account.
  2. Under Note, type something like wedding site admin.
  3. Set Expiration to custom and pick a date after your wedding (e.g. 12–13 months from now), or choose No expiration if GitHub offers it. This only affects your own login here — it never affects guests viewing the site.
  4. Under Select scopes, tick only public_repo.
  5. Click Generate token at the bottom, then copy the code it shows you (starts with ghp_). GitHub only shows it once.
  6. Paste it into the box above and click Connect.

This token only lets this page read and write your public repositories. Don't share it with anyone else; you can revoke it any time from the same GitHub settings page.
